# excerise_library

Exercise demo images for the ToFit app: 1,746 JPGs (start and end position) for 873 exercises.

Layout: `exercises/<Exercise_Name>/<n>.jpg`, for example `exercises/3_4_Sit-Up/0.jpg`.

CDN URL (pin a commit so images never change underneath the app):
`https://cdn.jsdelivr.net/gh/xdevsoft0/excerise_library@<commit>/exercises/<path>`

Source: [yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db) at commit f00c92c, released into the public domain (see LICENSE.md).
